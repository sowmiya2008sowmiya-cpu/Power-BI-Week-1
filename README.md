# Power BI – Data Cleaning and Transformation

## Description

The Superstore Sales dataset was imported, cleaned, and transformed using Power Query for further analysis in Power BI.

## Tools Used

- Power BI Desktop
- Power Query
- Superstore Sales Dataset

## Data Preparation

- Imported the Superstore Sales dataset
- Changed Order Date to Date using Locale
- Changed Ship Date to Date using Locale
- Checked missing values using Column Quality
- Applied Trim and Clean transformations to text data
- Created Year column
- Created Month column
- Created Day of Week column
- Created Day column
- Created Name of Day for date-based analysis
- Applied all transformations using Close & Apply
