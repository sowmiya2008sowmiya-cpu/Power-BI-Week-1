# Power-BI-Week-1

Power BI Week 1 – Superstore Sales Data Cleaning and Transformation

## Superstore Sales Data Analysis

This project contains my Week 1 Power BI work using the Superstore dataset.

## Activities Completed

- Imported the Superstore dataset
- Changed Order Date using Locale
- Changed Ship Date using Locale
- Checked missing values using Column Quality
- Removed duplicate records
- Created Year column
- Created Name of Day column
- Applied transformations using Close & Apply

## Tool Used

- Microsoft Power BI Desktop
- Power Query
